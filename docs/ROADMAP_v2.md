# Roadmap v2.0 — Lisa AIOS

This roadmap outlines completed development milestones and strategic targets for future releases of Lisa AIOS.

---

## Completed Milestones (v1.0 → v2.2-ga)

- [x] **v1.0 Placement Edition:** Core 7-layer architecture, FastAPI gateway, LangGraph runtime, ToolEngine, and developer studio pages.
- [x] **v2.0 Redesign Shell (R1):** Clean 5-item consumer navigation, 10 canonical legacy redirects, and integrated Developer / AIOS portal.
- [x] **v2.1 Product Experience (R2):** Real-data Assistant chat streaming, Email agent intelligence, Files RAG integration, and simplified Inspector.
- [x] **v2.2-ga Release Hardening (R3):** Deletion of unreferenced legacy dashboard widgets, fake data removal, UX jargon cleanup, and accessibility enhancements.

---

## Next-Tier Deferred Capabilities

The following features are formally cataloged as deferred and prioritized for subsequent major revisions:

1. **Continuous Gmail Intelligence:** Periodic background polling daemon with push alerts for urgent arrivals.
2. **Jobs & Internships Agent:** Autonomous career opportunity tracker, resume matching, and application preparation assistant.
3. **Travel Planner Agent:** Multi-modal itinerary generator, flight/hotel price monitoring, and calendar integration.
4. **Calendar Agent:** Bi-directional synchronization with Google Calendar / Outlook for schedule management.
5. **Event Bus (Redis / Celery):** Distributed message broker for background job execution and asynchronous processing.
6. **Proactive Notifications:** System tray, desktop OS notifications, and browser push alerts for urgent items.
7. **Codebase Intelligence:** In-depth AST repository indexing, symbol cross-referencing, and codebase graph search.
8. **Voice Agent:** Streaming speech-to-text input and natural voice synthesis output for conversational interaction.
